# Held in Common

**A federated commons for creative work.** Everyone runs their own **node**, a
personal commons on a computer they control, and chooses what to **share** as
signed copies to a **commons** that anyone can host. Your work stays on your
machine unless you send a copy, and the terms you set (licence and CC signals)
travel with it.

### ⬇️ [Download the app](https://github.com/HeldInCommon/FederatedBios/releases/latest)

| Your computer | File |
|---|---|
| **Mac with Apple Silicon (M1 to M4)** | `Held-In-Common-macOS-AppleSilicon.dmg` |
| Linux: Ubuntu or Debian | the `.deb` file |
| Linux: any distro | the `.AppImage` file |
| Linux: Fedora or RHEL | the `.rpm` file |

Windows and Intel Macs aren't supported by the app yet. They can
[run it in Docker](https://github.com/HeldInCommon/FederatedBios/blob/main/commons/README.md).

## Install on a Mac

1. **Download** `Held-In-Common-macOS-AppleSilicon.dmg` from
   [the latest release](https://github.com/HeldInCommon/FederatedBios/releases/latest).
2. **Open the `.dmg`** and drag **Held In Common** into **Applications**.
3. **Open it from Applications.** The app is signed and notarized by Apple, so
   it opens without warnings.
4. **Choose "A node"** and give it a name, for example "Studio laptop". People
   see this name next to your profile.
5. **Add your profile:** pick a handle (your `@name`) and a passphrase. A
   forgotten passphrase can't be recovered, so choose one you'll remember.
6. **Write down your recovery code** when it's shown (it appears once) and keep
   it offline. It takes your handle back if your keys are ever stolen.
7. **Publish**, then **share to a commons** using the address (and invite code,
   if you have one) from your host.

The full guide, including Linux, joining a commons and hosting one, is in
[INSTALL.md](https://github.com/HeldInCommon/FederatedBios/blob/main/docs/INSTALL.md).
